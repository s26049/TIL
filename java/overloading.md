## 메소드 오버로딩
**이름이 같고 매개변수가 다른 메소드를 여러개 정의하는 것**을 메소드 오버로딩이라고 한다.<br>

> **오버로딩 규칙**
메소드 이름은 같아도 매개변수의 타입 및 순서만 다르다면 오버로딩이 가능하다. <br>
```java
add(int a, int b)
add(int a, int b, int c)
add(double a, double b)
```
<br>

하지만 반환 타입이 다른건 인정하지 않는다.<br>다음은 컴파일 오류의 예시이다.<br>
```java
int add(int a, int b)
double add(int a, int b)
```

**메소드 시그니쳐**
자바에서 메소드를 구별할 수 있는 고유한 식별자나 서명을 뜻한다. 메소드의 이름과 매개변수의 타입(순서 포함)으로 구성되어있다.
<br>
반환 타입은 메소드 시그니쳐가 아니다.
